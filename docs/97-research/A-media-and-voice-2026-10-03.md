## A. Image generation with real product references
Purpose: creatives for hilsa pickle, mustard oil, honey, ghee, pink salt where the real jar/bottle stays recognisable across backgrounds, seasons and formats; Bangla headline text in-image; brand-kit consistency.

1. **Google Gemini image (Nano Banana family)**: REST via Gemini API; official SDKs Python/JS/Go; PHP via community or plain HTTP. Pricing (official): Nano Banana 2 (`gemini-3.1-flash-image`) $0.045/0.5K, $0.067/1K, $0.101/2K, $0.151/4K; Lite $0.0336/1K; Nano Banana Pro (`gemini-3-pro-image`) $0.134/1K-2K, $0.24/4K; Gemini 2.5 Flash Image $0.039; batch half price. Pro accepts up to 14 reference images with consistency (3P). n8n built-in Gemini node has Generate/Edit Image. MCP community only. Free tier content "used to improve"; paid tier not (official). Commercial use allowed; invisible SynthID watermark. Bangla text rendering UNVERIFIED: test. Imagen 4 reportedly deprecated, sunset 17 Aug 2026 (3P): do not build on it.
2. **OpenAI gpt-image-1.5 / gpt-image-2**: REST, official SDKs, PHP community client; already billed. Per-token (official): gpt-image-1.5 text in $5/M, image in $8/M, output $32/M; gpt-image-2 output $30/M; 1-mini output $8/M. Per image (3P): 1.5 at 1024² low $0.009 / medium $0.034 / high $0.133; batch 50%. Native edits/references. n8n OpenAI node. Outputs owned by user; API inputs not used for training by default. GPT Image 2 reviewers claim correct Bengali conjuncts (3P): verify on real labels.
3. **Black Forest Labs FLUX.2 / FLUX.1 Kontext**: REST, 1 credit = $0.01. FLUX.2 pro from $0.03/MP (edit $0.045), max $0.07, klein $0.014; Kontext pro $0.04, max $0.08 (official). Also on fal.ai (FLUX.2 dev $0.012/MP) and Replicate. Strong photoreal product shots; Bangla text weak (UNVERIFIED).
4. **Ideogram 3.0**: 3P pricing Turbo $0.03, Default $0.06, Quality $0.09; +Character Reference $0.10-0.20. Best Latin text; non-Latin "unpredictable": poor Bangla fit.
5. **Midjourney**: no official API; ToS prohibits automation; wrappers risk the account. Exclude.
6. **Adobe Firefly Services**: enterprise-only, no public per-image price. Exclude.
7. **Stability AI**: Stable Image Ultra $0.08/img, 25 free credits, $20/mo = 6,000 credits (3P). Weaker consistency; cheap generic fallback only.

Cheapest first-party multi-reference editing with a paid-tier no-training clause, native n8n node, credible Bangla-text path to A/B. **INTEGRATE.** Transport: direct REST behind an HQ `ImageGenerator` contract (prompt, reference images[], size, brand-kit id). Replacement: LOW (same shape across vendors). Risks: AI-disclosure expectations on Meta; hallucinated label text (re-check legal text, CRPA s.44); free-tier data use; Imagen sunset; non-exclusive outputs.

## E. Speech-to-text for Bangla voice notes
1. **ElevenLabs Scribe v2**: $0.22/audio-hour batch, $0.39/hr realtime (official); Bengali in the "High Accuracy" tier (WER 5-10%) (official). Verified n8n node incl. STT; official hosted MCP. REST, no PHP SDK.
2. **Google Cloud STT v2 `chirp_3`**: explicit `bn-BD` and `bn-IN` (official; excerpt listed them under the `eu` region: check `asia` availability for latency). $0.016/min (3P). Official PHP library. n8n HTTP.
3. **OpenAI**: whisper-1 $0.006/min, gpt-4o-transcribe $0.006/min, gpt-4o-mini-transcribe $0.003/min (official). Bengali NOT in OpenAI's "performs well" list; stock Whisper on Bengali shows high WER (3P). Keep as the Banglish experiment.
4. **Deepgram Nova-3**: Bengali added Jan 2026 (official); code-switch mode covers 10 languages WITHOUT Bengali (official); $0.0043/min pre-recorded; $200 free credit. Streaming Bengali UNVERIFIED.
5. **AssemblyAI**: Bengali only on Universal-2, ">50% WER" tier (official). Unusable.
6. **Azure STT**: `bn-IN` only; no `bn-BD` (official).
7. **Gemini 3.5 Transcribe**: $0.003/min in, $0.002/min out (official); Bengali list UNVERIFIED; copes with noise/mixed language (opinion).

Recommendation: run a 50-note bake-off from real WhatsApp audio (clean, noisy, Banglish) across Scribe v2, chirp_3 bn-BD, gpt-4o-transcribe, Gemini 3.5 Transcribe; score by human-rated usefulness. Provisional primary ElevenLabs Scribe v2; fallback Google chirp_3 bn-BD (only Bangladesh locale). **INTEGRATE.** Transport: direct REST behind a `Transcriber` contract (audio in; text + language + confidence out); WhatsApp OGG/Opus converted with ffmpeg in-house. Replacement: VERY LOW. Risks: no vendor promises romanised output; code-switch unverified; audio privacy (ElevenLabs/Deepgram training terms UNVERIFIED); Google EU routing for bn-BD.

## G. Telephony / AI phone agents in Bangladesh
Facts: Twilio outbound to BD $0.0600/min, inbound $0.0040/min; BD local numbers from $1/mo but require a local business address proof (commercial register/utility bill/tax notice; no PO Box) (official); two-way SMS not supported in BD; sender-ID registration mandatory since 8 Sep 2025 (official). Plivo: outbound BD $0.046/min; inbound "Not Supported" (official). Telnyx: BD numbers from $250/mo with ID, business registration, LOI (official). Vonage: BD mobile numbers on request, 2-week turnaround. Exotel: no BD evidence (UNVERIFIED). Voice-agent platforms Retell ($0.07-0.31/min all-in), Vapi ($0.05/min + providers, BYO Twilio/Telnyx/Plivo/Vonage), Bland ($0.09/min): all can dial BD via trunks; none publish BD support. Local IPTSP licensees (Amber IT, MiME, IPCallBD) sell SIP trunking and "bulk voice call" with API (vendor claims, 3P); programmable API quality UNVERIFIED. BTRC: DND registry for promotional calls/SMS; BTRC Act 2001 penalises "annoyance by telephone"; enforcement against VoIP bypass; calls from foreign CPaaS arrive via IGW with foreign/unknown CLI that Dhaka customers often reject. IPTSP guideline PDF not parsed: clauses on auto-dialers/AI voices UNVERIFIED.

Recommendation: **WAIT.** No inbound BD number without KYC friction or $250/mo; outbound CLI foreign; no vendor proves streaming Bangla STT for a live agent; BTRC posture on automated calls unclear. If piloted later: Retell or Vapi + Twilio BYO for outbound order-confirmation only (consent captured at checkout), Azure bn-BD TTS, legal opinion first. Joy prepares: nothing now; later trade licence + utility bill + signatory ID. Risks: regulatory, customer distrust of unknown CLI, $0.06+/min before the AI, Bangla latency.

## Cross-cutting notes
- n8n (self-hosted) coverage: built-in OpenAI (image gen/edit, transcribe, TTS), Google Gemini (image gen/edit, transcribe, video), Bannerbear; verified partner nodes ElevenLabs, HeyGen, Cloudinary; official community Creatomate; community Deepgram, fal.ai; everything else HTTP Request.
- MCP: official servers from ElevenLabs (hosted OAuth), HeyGen, Cloudinary, Canva, Replicate; community for OpenAI/Gemini images, fal.ai; Placid lists MCP. Use only for human-in-the-loop exploration; production via the HQ adapter.
- PHP: official libraries for Google Cloud Speech/TTS and Twilio; OpenAI/Gemini via community clients; everything else plain REST.
- Rights pattern: OpenAI API and Gemini paid tier = no training on inputs, outputs owned, non-exclusive; Gemini images carry SynthID; HeyGen/Runway/Kling/Veo block or require consent for real likenesses; ElevenLabs clones only your own verified voice.
- Volatility: in six months Sora's API was killed, Imagen 4 reportedly sunset, PlayHT reportedly vanished, remove.bg prices diverge, HeyGen dropped free API credits. Keep every adapter one-file replaceable.
