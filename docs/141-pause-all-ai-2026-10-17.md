## Plan

1. A durable pause state in its own one-row table, read fresh (no cache) by one reader that answers "paused" whenever the row cannot be read or is missing.
2. Every AI execution entry point reads it before any model call and before any tool call an agent proposed.
3. Two operations, two permissions: pause (`hq.ai.pause`) and re-enable (`hq.ai.resume`), each behind `GroupWideAuthority`, each needing a reason, each audited with actor, `scope = group`, before, after and reason.
4. Web routes and console commands for both, the routes added to the pinned global switch list.
5. UI: the control on the console live panel and the posture screen, a banner on every page while paused, Bangla strings, a confirm dialog with a reason; a restricted person sees the state and no control.
6. Tests per ruling 7, then this record is completed below.
